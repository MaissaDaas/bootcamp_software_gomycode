Activité CSS : la typographie

Durée conseillée : 60 minutes.

Comment travailler ?
  1. Ouvre ce fichier dans ton éditeur (par exemple VS Code) et dans ton navigateur.
  2. Va dans le bloc <style id="zone-etudiant"> en haut du fichier.
  3. Remplace chaque commentaire À FAIRE par du CSS, enregistre, puis actualise le navigateur.
  4. Ne modifie pas le HTML ni l’autre bloc <style>.

Justifié : la justification répartit l’espace entre les mots pour aligner le texte sur les deux côtés du conteneur lorsque cela est possible, ce qui se voit surtout sur plusieurs lignes.
